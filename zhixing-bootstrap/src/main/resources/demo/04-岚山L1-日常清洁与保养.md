# 岚山 L1 办公咖啡机 · 日常清洁与保养

## 每日（建议下班前）

- 倒空接水盘与渣盒并用清水冲洗
- 湿布擦拭冲泡口与外壳（禁用研磨性清洁剂）
- L1 Pro：执行一次奶路自动清洗（触控屏 → 保养 → 奶路清洗）

## 每周

- 取出冲泡器（关机状态下按释放钮）用清水冲洗，晾干后装回
- 清洁豆仓内壁，检查干燥剂卡槽（变色即更换）

## 每月

- 触控屏 → 保养 → 除垢程序（约 25 分钟，需使用岚山除垢剂一袋）
- 检查滤水器：硬水地区建议每月更换，纯净水地区可延至 3 个月

## 每季度

- 磨豆刀盘吸尘清理（随机附赠小刷）
- 检查电源线与插头有无破损

## 提示

长期（>7 天）不使用时：倒空水箱与豆仓，执行一次除垢后关机断电，防潮存放。
机器长期闲置后首次使用前，先空烧 2 次热水再制作饮品。
