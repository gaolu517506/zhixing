# 岚山 L1 办公咖啡机 · 保修与售后政策

## 保修期限

- 整机保修 2 年（自验收签收日起算）
- 核心萃取组件（冲泡器、锅炉）保修 3 年
- 易损耗材（磨豆刀盘、密封圈、奶管）不在免费保修范围，可按备件价购买

## 保修条件

1. 机器序列号完整可查，且在保修期内
2. 使用岚山认证耗材导致的非人为故障
3. 未私自拆机、改装或外接非标电源

## 报修流程

1. 拨打售后专线或提交工单，提供机器序列号与故障现象
2. 远程诊断（48 小时内响应）
3. 无法远程解决的，长三角/珠三角地区 3 个工作日上门，其他地区 5-7 个工作日
4. 同一故障 30 天内两次维修未解决的，可申请整机换新

## 企业服务

- 年度保养套餐：每年 2 次上门深度除垢清洁
- 耗材订阅：咖啡豆、清洗剂按月配送
